# Wild Oasis App

## Overview
Wild Oasis is a hotel booking application where users can search and book reservations, select number of guests, choose cabin types, and log in for a personalized experience.

## Features
- User login with automatic name registration
- Booking system with multiple guests and cabin types
- Interactive forms and reservation management
- Responsive design and modern UI

## Tech Stack
- HTML, CSS, Tailwind CSS
- React.js
